# Libgen Service

Локальный клиент для поиска и скачивания книг из Library Genesis **без рекламы,
всплывающих окон и цепочек редиректов**.

Сервис работает как обычный HTTP-сервер на вашей машине: он сам обращается к
зеркалам Libgen, разбирает результаты и отдаёт файлы напрямую. Браузер видит
только один локальный сайт, поэтому сторонние скрипты, баннеры и трекеры не
загружаются вообще.

```
┌────────────┐      ┌──────────────────┐      ┌──────────────┐
│  браузер   │ ───► │ libgen-service   │ ───► │ зеркала      │
│ localhost  │ ◄─── │ (этот проект)    │ ◄─── │ Libgen + CDN │
└────────────┘      └──────────────────┘      └──────────────┘
```

## Возможности

- Поиск по названию, автору, ISBN, DOI и MD5.
- Фильтры: расширение, язык, год, раздел; сортировка и постраничный вывод.
- Карточка книги: автор, издательство, год, ISBN, описание, оглавление, файлы.
- Скачивание в один клик с проверкой MD5 — файл приходит уже с нормальным именем.
- Обложки книг (проксируются и кешируются локально).
- Автоматический выбор рабочего зеркала, повторы и backoff при сбоях.
- SQLite-кеш результатов и файлов, чтобы не дёргать Libgen повторно.
- Веб-интерфейс на русском и CLI. Никаких внешних CDN, шрифтов и аналитики.

## Установка

Нужен Python 3.10+.

```bash
cd /path/to/libgen
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

Либо без установки пакета:

```bash
pip install -r requirements.txt
python3 -m libgen_service --help
```

## Быстрый старт

```bash
./run.sh
```

Откроется <http://127.0.0.1:8765/>. Если браузер не нужен:

```bash
python3 -m libgen_service serve --host 127.0.0.1 --port 8765
```

Остановка — `Ctrl+C`.

## CLI

```bash
# Поиск
libgen-service search "clean code" --ext pdf --per-page 5
libgen-service search "9780132350884" --mode isbn
libgen-service search "python" --lang eng --year-from 2020 --sort year_desc

# Подробности: по edition id или по MD5
libgen-service info 138192056
libgen-service info 184c16eae281bf2ebea72eb6d7aa6f6d

# Скачивание (проверка MD5 включена)
libgen-service get 184c16eae281bf2ebea72eb6d7aa6f6d -o ~/Downloads/books

# Состояние зеркал
libgen-service mirrors --probe

# Машиночитаемый вывод
libgen-service search "dune" --json
```

`get` принимает MD5 (его печатает `search`) либо можно взять ссылку из карточки
книги в веб-интерфейсе. Флаг `--no-verify` отключает проверку контрольной суммы.

## HTTP API

Сервер отдаёт JSON; веб-интерфейс использует те же эндпоинты.

| Метод и путь | Назначение |
| --- | --- |
| `GET /` | Веб-интерфейс |
| `GET /api/health` | Состояние сервиса и зеркал |
| `GET /api/mirrors?probe=1` | Список зеркал (с проверкой доступности) |
| `GET /api/search?q=...` | Поиск |
| `GET /api/book/{edition_id}` | Подробная карточка книги |
| `GET /api/file/{md5}` | Информация о файле по MD5 |
| `GET /api/resolve/{md5}` | Прямая ссылка на файл (без рекламной страницы) |
| `GET /api/cover/{md5}?libgen_id=...` | Обложка книги |
| `GET /api/download/{md5}` | Скачивание файла |

Параметры `/api/search`: `q` (обязательный), `mode` (`auto`, `isbn`, `md5`,
`doi`, `edonkey`), `topic`, `ext`, `lang`, `year_from`, `year_to`, `sort`
(`relevance`, `year_desc`, `year_asc`, `title`, `size_desc`, `added_desc`),
`page`, `per_page`.

Примеры:

```bash
curl "http://127.0.0.1:8765/api/search?q=clean+code&ext=pdf&per_page=3"
curl "http://127.0.0.1:8765/api/book/138192056"
curl -OJ "http://127.0.0.1:8765/api/download/184c16eae281bf2ebea72eb6d7aa6f6d"
```

## Настройки через переменные окружения

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `LIBGEN_MIRRORS` | встроенный список | Зеркала через запятую |
| `LIBGEN_TIMEOUT` | `20` | Таймаут запроса, секунды |
| `LIBGEN_RETRIES` | `3` | Число попыток на запрос |
| `LIBGEN_MIN_INTERVAL` | `0.4` | Минимальная пауза между запросами к зеркалу |
| `LIBGEN_CACHE_DIR` | `~/.cache/libgen-service` | Каталог кеша |
| `LIBGEN_CACHE_TTL` | `600` | Время жизни кеша, секунды (`0` — бессрочно) |
| `LIBGEN_USER_AGENT` | Chrome UA | User-Agent |
| `LIBGEN_PROXY` | — | HTTP(S)-прокси |

По умолчанию используются `libgen.li`, `libgen.la`, `libgen.bz`, `libgen.gl`:
они отвечают стабильнее, чем `libgen.is` и родственные домены. Если ваши
зеркала другие — переопределите список:

```bash
LIBGEN_MIRRORS="https://libgen.li,https://libgen.bz" ./run.sh
```

## Как это работает

1. **Поиск.** Запрос уходит в `batchsearchindex.php`; для ISBN/DOI/MD5 сервис
   при необходимости переходит по ссылке, которую возвращает Libgen, и
   разбирает обычную таблицу результатов. Метаданные добираются через
   `json.php`.
2. **Скачивание.** Сервис открывает `ads.php?md5=...`, вытаскивает настоящую
   ссылку `get.php?md5=...&key=...`, идёт по ней с нужным `Referer` и
   перенаправляет поток файла вам. Рекламная страница и её скрипты в браузер
   не попадают.
3. **Проверка.** Скачанный файл сверяется с MD5; при несовпадении он удаляется
   и возвращается ошибка.
4. **Кеш.** Результаты поиска и обложки кешируются в SQLite и на диске.

## Тесты

```bash
python3 -m pytest -q          # офлайн-тесты, без сети
python3 -m pytest -m network  # живые проверки настоящих зеркал
```

Офлайн-тесты используют записанные ответы Libgen из `tests/fixtures/`, поэтому
проходят без интернета.

## Структура проекта

```
libgen_service/
  api.py        поиск, метаданные, скачивание, обложки
  parsers.py    разбор HTML и JSON Libgen
  http.py       HTTP-клиент, зеркала, повторы, троттлинг
  cache.py      SQLite TTL-кеш
  server.py     локальный HTTP-сервер и API
  cli.py        команды search / info / get / serve / mirrors
  web/index.html  одностраничный интерфейс без внешних ресурсов
tests/          офлайн- и сетевые тесты
```

## Правовая оговорка

Проект — технический клиент к публично доступному каталогу Library Genesis.
Он не хранит и не распространяет книги. Скачивая материалы, вы сами отвечаете
за соблюдение авторских прав и законов вашей юрисдикции. Используйте сервис
только для книг, которые вы вправе читать и хранить.
